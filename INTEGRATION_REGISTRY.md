## 1. Biometric L1 Registered Device (RD) Service Connector

ADCS integrates with certified UIDAI L1 Registered Devices (such as Mantra MFS100 / Morpho MSO 1300 E3) through a secure local loopback protocol:

```text
[ CITIZEN COUNTER UI ] ──(HTTPS/WSS)──> [ LOCALHOST:11100 RD SERVICE ]
                                                │
                                        (Hardware Secure Enclave)
                                                │
                                    [ CAPTURE ENCRYPTED PID BLOCK ]
                                                │
[ ADCS API GATEWAY ] <──(AES-256 PID)───────────┘
        │
        ▼ (Strict Policy: ZERO RAW BIOMETRIC STORAGE)
[ NPCI / UIDAI AEPS SWITCH ]
```

### Connector Technical Contract:
- **Port Binding:** Localhost Port `11100` (HTTP/HTTPS loopback).
- **Endpoint:** `RDSERVICE` (Device Discovery), `CAPTURE` (Encrypted PID Data Extraction).
- **PID Content Specification:**
  - `ci`: Certificate Identifier matching UIDAI production public key.
  - `Hmac`: SHA-256 integrity hash of unencrypted biometric sample computed inside secure hardware enclave.
  - `Data`: AES-256 encrypted biometric structure (ISO 19794-2/4 minutiae).
- **Compliance Guarantee:** The raw fingerprint image never touches the operating system filesystem, memory heap, or ADCS backend database.

## 2. NPCI Unified Payments Interface (UPI) Intent & BBPS Switch

### NPCI UPI Intent URI Schema:
All payment links generated by `/api/payments/create-order` conform to the statutory NPCI UPI deep-linking specification:

```text
upi://pay?pa=akuldravin%40icici&pn=AKUL+DRAVIN+DIGITAL+SERVICES&am={amount}&cu=INR&tn={order_id}&tr={transaction_ref}&mc=5399
```

- `pa`: Verified Payee VPA address.
- `pn`: Payee Legal Business Name (AKUL DRAVIN DIGITAL SERVICES).
- `mc`: Merchant Category Code (5399 - Miscellaneous General Services).
- `tr`: Unique transaction tracking reference.
- `tn`: Order reference number.

### Bharat Bill Payment System (BBPS) Connector:
- **Switch Protocol:** ISO 8583 / REST JSON bridge through authorized BBPOU Partner Switch.
- **Workflow:** 
  1. Consumer Account Lookup (`fetch-bill`).
  2. Biller verification with customer name and outstanding due amount.
  3. Payment authorization and settlement via escrow account.
  4. Instant BBPS Reference Number generation (`BBPS-TXN-{12_DIGITS}`).
